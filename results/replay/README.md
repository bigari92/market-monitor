# Replay — mechanical validation, NOT a backtest

Generated by `python -m market_monitor.cloud.run replay --months 24`.

Computes no forward return, reports no performance, ranks no outcome. It exists to show
the exit rules firing on real price history instead of only on synthetic fixtures.

It could not be a backtest: the universe is today's registrants, so every name in it
survived to today (RECOVERY.md defect 1). The factors are honest point-in-time, but a
point-in-time factor over a survivor-only universe is still a biased sample. Any
performance number computed from these files would be measuring survival.

The live record is `results/tracking/`. A replay never writes there.
